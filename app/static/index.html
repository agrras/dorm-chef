CIS 5270 course project

Can a small AI write a good dorm recipe and follow the rules?

You tell it what’s in your dorm room, and sometimes a rule like “vegan” or “no cheese.” It has to write a short recipe using only those ingredients. We trained a small model two different ways, then graded 2,200 of its recipes to see what actually helped.

The task
1

You give it a pantry

For example: rice, eggs, kimchi, soy sauce, green onions. Sometimes with a rule: vegan, Italian-style, no cheese.

2

It writes a recipe

Short and student-friendly: the kind you can make with a hot plate and one pan.

3

It has to obey

  • Use only your ingredients (plus salt, pepper, oil, water, butter)
  • 3 to 7 steps
  • Done in 15 minutes
  • Follow the rule, if there is one
Three models, compared

Base

GPT-4.1-nano straight out of the box, with no extra training. This is our starting line.

No fine-tuning

SFT

Trained by example. It was shown many recipes that follow the rules and learned to copy that style.

Supervised fine-tuning

DPO

Trained by preference. It was shown pairs of a good recipe and a bad one (too many steps, wrong ingredients) and learned to prefer the good one.

Direct preference optimization

    How the recipes were graded

    The AI judge

    A second model (GPT-4.1-mini) reads each recipe and answers yes/no questions: only pantry ingredients? 3–7 steps? Under 15 minutes? Followed the rule? These are the project’s official scores.

    The rule check

    A plain program, with no AI, re-asks the same questions using counting and word lists. We added it as a cross-check on the judge, and it also powers the agent’s self-checking.

    How the agent works

    The same rules we used to grade the models can run while a model is cooking. That turns the grader into a guard-rail.

    DraftThe model writes a recipe from your pantry and rule.
    CheckThe rule check tests it: only your ingredients? 3–7 steps? Under 15 minutes? Rule followed?
    Send backIf something fails, the exact problem is sent back to the model: “Not vegan: uses chicken.”
    FinishThe model rewrites it. This repeats up to a few rounds, until every check passes.

    ✓This website replays saved results from the trained models. Nothing here calls an AI.

    –The fine-tuned models were hosted on Azure during the course. Those hosted copies are no longer running, so the live agent isn’t on this page. Hosting a fine-tuned model costs money for every hour it’s switched on.
    Run or deploy it yourself

    The app is in the app/ folder of the project. It runs with no keys in a clearly labelled demo mode.

    git clone https://github.com/agrras/dorm-chef
cd dorm-chef
pip install -r app/requirements.txt
uvicorn app.server:app          # then open http://localhost:8000

    Use a real model

    Set ANTHROPIC_API_KEY to use Claude. Or set AZURE_OPENAI_API_KEY plus the three deployment names in app/.env.example to use the fine-tuned base, SFT and DPO models.

    Put it online

    Any Python host works (Render, Fly.io, Railway). Start command: uvicorn app.server:app --host 0.0.0.0 --port $PORT. Add keys as environment variables, never in the code. A built-in rate limit protects your API bill.
